# ツール選定（たたき台）

個人・無料から始めて、あとから手間をかけて伸ばせる構成を優先する。

## おすすめ構成（制作の流れ順）

### 1. 歌声 → `voice/`
- まず **VOICEVOX のソング機能** で試し、物足りなければ **NEUTRINO** か **Synthesizer V** に移る。
- [ ] どのソフトに「つくよみちゃん」の歌声が用意されているか、配布元の公式情報で確認する（未確認）。
  - 歌声がない場合は、別の歌声を使うか、話し声だけの演出にするかを決める。
- 歌詞は `voice/lyrics/`、譜面（MusicXML / MIDI）は `voice/vocal-data/`、書き出した wav は `voice/renders/` に置く。

### 2. 伴奏・ミックス → `music/`
- 最初はオリジナル曲か、ライブで使ってよいフリー伴奏にする。
  - 既存曲のカバーはライブで使うと権利の手続きが必要になることがある。
- 歌声と伴奏は Audacity などで合わせ、`music/mix/` に置く。

### 3. アバター → `avatar/`
- **VRM 形式** で揃える。公式やファンが配布している 3D モデルがあればそれを使い、なければ **VRoid Studio** で作る。
- [ ] キャラクターの利用規約（ライブ配信・商用・改変の可否）を確認し、このフォルダにメモする。

### 4. ステージ・モーション → `stage/`
- **Unity + UniVRM** を使い、Timeline で「歌の wav、ダンスモーション、口パク、カメラ」を時間に合わせて並べる。
- ダンスはフリーのモーション（VRMA / MMD モーション）から始める。口パクは音声から自動で作る。
- 手軽に済ませる案：VRM を読み込める既存のビューアーと OBS を組み合わせる。

### 5. 投影 → `stage/projection/`
- Unity の画面をもう一台のディスプレイに全画面で出すか、OBS の全画面プロジェクター機能で映す。
- ホログラム風に見せたい場合：背景を黒にしてハーフミラーに映す（ペッパーズ・ゴースト）。

## 最初の一歩（目安 1〜2 週間）
短い 1 曲（30 秒〜1 分）だけで次の流れを一度通しで作る。

1. 歌声を作る
2. アバターが口パクして揺れる
3. ディスプレイに映す

そのあとで、ダンス・衣装・演出を少しずつ豊かにしていく。
