# ツール選定

個人・無料から始めて、あとから手間をかけて伸ばせる構成を優先する。

## 決定した構成（制作の流れ順）

### 1. 歌声 → `voice/`
- まず **VOICEVOX のソング機能** で試す。
- **歌手は「ずんだもん」に決定**（2026-11-01、試しのフレーズで春日部つむぎ・波音リツと聴き比べて選んだ）。
  - 公開時はクレジット表記「VOICEVOX:ずんだもん」が必要。ずんだもんの利用規約も確認する。
- 品質を上げるなら **Synthesizer V**。GPU を活用できる無料の **NEUTRINO** も候補。
- [ ] どのソフトに「つくよみちゃん」の歌声が用意されているか、配布元の公式情報で確認する（未確認）。
  - 歌声がない場合は、別の歌声を使うか、話し声だけの演出にするかを決める。
- 歌詞は `voice/lyrics/`、譜面（MusicXML / MIDI）は `voice/vocal-data/`、書き出した wav は `voice/renders/` に置く。

### 2. 伴奏・ミックス → `music/`
- 1 曲目「月夜のステージ」（song01・オリジナル・約 52 秒）：歌詞 `voice/lyrics/song01.txt`、譜面 `voice/vocal-data/song01.musicxml`、歌声 `voice/renders/song01_vocal.wav`、伴奏 `music/instrumentals/song01_inst.wav`、ミックス `music/mix/song01_mix.wav`。伴奏は Python で合成した仮のもの。
- 最初はオリジナル曲か、ライブで使ってよいフリー伴奏にする。
  - 既存曲のカバーはライブで使うと権利の手続きが必要になることがある。
- 歌声と伴奏は Audacity などで合わせ、`music/mix/` に置く。

### 3. アバター → `avatar/`
- **VRoid Studio** で作成し、**VRM 形式** で書き出す。
- **現行モデルは暫定**：ずんだもん（人型）3D モデルセット ver.A1 を使用中。将来、**ディフォルメ寄りのモデルに作り直す予定**（公式モデルを素体に改変する場合は権利者 SSS LLC. への問い合わせが必要）。
  - Unity 側はモデルを差し替えやすくしてある：モデルごとの設定（VRM のパス、腕の角度、カメラ距離、口パク用の表情など）は `stage/unity/Assets/Resources/AvatarProfiles/` の AvatarProfile にまとめている。
- 配布キャラクター（例：つくよみちゃん）のモデルを使う場合は、商用・ライブ利用が可能な規約か確認する。
- [ ] キャラクターの利用規約（ライブ配信・商用・改変の可否）を確認し、このフォルダにメモする。

### 4. ステージ・モーション → `stage/`
- **Unity + UniVRM** を使い、Timeline で「歌の wav、ダンスモーション、口パク、カメラ」を時間に合わせて並べる。
- ダンスはフリーのモーション（VRMA / MMD モーション）から始める。口パクは音声から自動で作る。
- 手軽に済ませる案：VRM を読み込める既存のビューアーと OBS を組み合わせる。

### 5. 投影 → `stage/projection/`
- Unity の画面をもう一台のディスプレイに全画面で出すか、OBS の全画面プロジェクター機能で映す。
- ホログラム風に見せたい場合：背景を黒にしてハーフミラーに映す（ペッパーズ・ゴースト）。

## 最初の一歩（目安 1〜2 週間）
短い 1 曲（30 秒〜1 分）だけで次の流れを一度通しで作る。

1. [x] 歌声を作る（2026-11-01：VOICEVOX・ずんだもんで 12 秒の試しフレーズ）
2. [x] アバターが口パクして揺れる（2026-11-01：Unity `stage/unity` の Stage シーンで確認）
3. [ ] ディスプレイに映す → **最後のフェーズ**で、投影用の 2 台目の PC に接続して行う

そのあとで、ダンス・衣装・演出を少しずつ豊かにしていく。
