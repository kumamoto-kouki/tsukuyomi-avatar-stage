# tsukuyomi-avatar-stage

AIアバターを作り、ディスプレイに投影して歌を歌わせるライブプロジェクト。

## フォルダ構成

| フォルダ | 用途 |
|---|---|
| `docs/` | 企画メモ、ツール選定、手順書 |
| `avatar/models/` | アバターの3D/2Dモデル本体（.vrm など） |
| `avatar/textures/` | 衣装・テクスチャ素材 |
| `avatar/exports/` | 書き出したモデル |
| `voice/lyrics/` | 歌詞 |
| `voice/vocal-data/` | 歌声合成のプロジェクトファイル |
| `voice/renders/` | 書き出した歌声（wav） |
| `music/instrumentals/` | オケ・伴奏音源 |
| `music/mix/` | 歌声とオケのミックス |
| `stage/scenes/` | ライブ会場・ステージのシーン |
| `stage/motion/` | ダンス・モーションデータ |
| `stage/projection/` | ディスプレイ投影の設定 |
| `assets/` | 参考資料・画像など共通素材 |
| `output/` | 録画・切り抜きなどの完成物 |
| `scripts/` | 自動化スクリプト |

使用ツールは未確定（`docs/` で検討）。
